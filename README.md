# Table4 — числовые значения из таблицы №4

**[Table4.exe](Table4.exe)** — программа для Windows 10/11 (64 бит). Установка не нужна, это один файл.

Программа открывает протокол испытаний в формате `.docx`, находит в нём **таблицу №4**
и показывает все числовые результаты (например, `127 ± 15` и `0,0127 ± 0,0015`).
Значения вида «Менее 10» / «Менее 0,001» пропускаются.

## Как пользоваться

1. Запустите `Table4.exe`.
2. Откройте протокол кнопкой **«Открыть файл…»** или перетащите `.docx` в окно
   (можно перетащить файл и прямо на значок `Table4.exe`).
3. В окне появятся два раздела:
   - **СВИНЕЦ** — все числовые значения свинца из таблицы №4;
   - **ОБЩИЙ БРОМ** — все числовые значения общего брома.

   Каждая строка — две плитки: слева значение в **мг/кг**, справа в **%**, как в таблице.
   Слева серым показан номер компонента/материала.
4. **Нажатие на плитку** сразу копирует её текст в буфер обмена, и плитка загорается жёлтым.
   Плитки остаются подсвеченными, пока вы не нажмёте **«Сброс»**. В буфере обмена всегда
   значение последней нажатой плитки — она выделена рамкой и подписью «в буфере».
5. Внизу — **статистика таблицы №4**:
   - сколько всего числовых значений в таблице (строк с числами по всем элементам,
     с разбивкой по элементам и количеством ячеек мг/кг + %);
   - сколько строк со значением **BL**.

Если Windows SmartScreen предупреждает о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Как программа ищет таблицу

- Таблица №4 — первая таблица после абзаца, начинающегося с «Таблица №4».
  Если таблица разорвана и продолжается после подписи «Продолжение таблицы №4»,
  продолжение тоже учитывается.
- Колонки находятся по заголовкам: «Определяемая характеристика», «мг/кг», «%»,
  «Интерпретация результата».
- Число — это значение, в котором есть цифры и нет букв и знаков `<`, `>`.

## Сборка из исходников

Нужен [Go](https://go.dev/dl/) 1.24+.

```sh
./build.sh
```

или вручную:

```sh
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-H windowsgui -s -w" -o Table4.exe .
```

Проверить разбор без Windows (вывод в консоль): `go run . протокол.docx`.

| Файл | Что внутри |
|---|---|
| `parser.go` | чтение `.docx`, поиск таблицы №4, извлечение значений и статистики |
| `main_windows.go` | окно программы (библиотека [walk](https://github.com/lxn/walk)) |
| `main_other.go` | консольный вариант для Linux/macOS |
| `winres/`, `rsrc_windows_amd64.syso` | иконка и манифест Windows |
